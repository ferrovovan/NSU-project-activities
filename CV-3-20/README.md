# Задача CV-3-20


### Описание задачи
Система распознавания объектов на складе.
Интегрирвать CV-2-04 и CV-2-01 для сбора статистики по цвету и размеру объектов с изображения и формирования отчёта.  

**Подробное руководство по воплощению задачи:**
1. Найдите объекты.  
2. Классифицируйте по цвету (CV-2-04) и размеру (CV-2-01).  
3. Присвойте категорию: 'малый красный', 'большой синий'.  
4. Подсчитайте по категориям.  
5. Выведите отчёт.

Список используемых библиотек: **numpy**, **opencv**  
Источники данных: Синтетические данные

### Документация (описание воплощения)

Решение хранится в одном файле `warehouse_object_recognition.py`.  
Этот модуль реализует систему анализа изображений со склада: программа определяет объекты по контурам, оценивает их **размер**, **цвет**, **форму (заглушка)** и формирует CSV-отчёт.  
Также доступен визуальный просмотр результата с наложением контуров на исходное изображение.

---

#### Общая структура

Код организован блочно и разделён на логические уровни:

1. **Главные функции:**
   - `main_process_file()` — обрабатывает реальное изображение, выполняет анализ и сохраняет отчёт.
   - `example_synthetic()` — создаёт искусственное тестовое изображение с простыми фигурами трёх цветов.

2. **Промежуточные шаги анализа:**
   - `process_image()` — объединяет все этапы обработки: поиск контуров, анализ цвета и размера, построение итогового отчёта и визуализацию.  
   - `save_to_csv()` — сохраняет результаты анализа в CSV-таблицу.
   - `classify_contour_color()` — определяет преобладающий цвет внутри контура.
   - `analyze_contour_size()` — классифицирует объект по площади на «малый», «средний», «большой».
   - `detect_shape_stub()` — функция-заглушка для анализа формы (возвращает `"неизвестный"`).

3. **Вспомогательные и визуальные функции:**
   - `create_base_color_masks()` — создаёт набор масок для базовых цветов: красного, синего и зелёного.  
   - `create_extra_color_masks()` — создаёт набор масок для дополнительных цветов цветов: жёлтого, оранжевого, чёрного, белого и серого.  
     Каждый цвет задаётся одним или несколькими диапазонами HSV через класс `ColorMask`.
   - `show_result()` — выводит исходное и обработанное изображение с наложенными контурами для наглядности.

---

#### Ключевые элементы реализации

- **Контуры объектов**  
  Извлекаются через функцию `counting_contours()` из предыдущего задания (`CV-2-01`), где применяется фильтрация по минимальной и максимальной площади.

- **Классификация цвета**  
  Реализована в функции `classify_contour_color(image_bgr, contour, masks)`.  
  Каждый контур сравнивается с набором цветовых масок, и выбирается цвет с наибольшим перекрытием.  
  Если число пикселей цвета внутри контура меньше 10 — цвет считается «неизвестным».

- **Определение размера**  
  Функция `analyze_contour_size(cnt)` использует площадь контура для грубой классификации по трём уровням:
  - `< 1000` — малый  
  - `1000–5000` — средний  
  - `> 5000` — большой

- **Определение формы (заглушка)**  
  Функция `detect_shape_stub(contour)` возвращает `"неизвестный"`.  
  В дальнейшем сюда можно добавить определение формы по аппроксимации многоугольника или моментам Гюйгенса.

- **Визуализация**  
  После анализа изображение выводится с наложенными контурами, подписанными цветами и размерами объектов.  
  Это позволяет визуально проверить правильность распознавания.

---

#### Сценарии запуска

В программе реализованы два режима работы:

- `--example_synthetic` — создаёт тестовое изображение с несколькими фигурами основных цветов, выполняет распознавание и сохраняет отчёт `report_synthetic.csv`.

- `--file <путь>` — обрабатывает указанное изображение, строит статистику по объектам и сохраняет отчёт `warehouse_report.csv`.  
  Кроме того, открывается окно с визуализацией результата (обведённые контуры, подписи и выделенные цвета).

---

#### Особенности архитектуры

Код построен по принципу **чистой иерархии задач**:  
низкоуровневые операции (поиск контуров, анализ цвета, запись в CSV) изолированы, а высокоуровневая логика (`process_image`, `main_process_file`) соединяет их без дублирования.  
Благодаря этому структуру легко расширить — например, добавить новые цвета или модуль определения формы без изменения остального кода.

Для разбора аргументов командной строки используется модуль **argparse** с взаимоисключающей группой параметров.



#### Примеры запуска

```bash
python3 warehouse_object_recognition.py --example_synthetic
```

```bash
python3 warehouse_object_recognition.py --file mypic.png
```
